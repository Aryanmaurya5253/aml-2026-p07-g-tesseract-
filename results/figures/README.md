# Generated figures

Figures are generated by the pipeline scripts and written to this directory:

- `run_eda.py`: monthly revenue, top products, top countries, invoices per customer, weekday revenue, and new-vs-returning customers.
- `build_rfm.py`: `rfm_distributions.png`, showing raw and `log1p` RFM distributions.
- `clustering.py`: K-Means elbow, silhouette, and provisional PCA plots.
- `clustering_advanced.py`: hierarchical silhouette, dendrograms, and DBSCAN k-distance plot.
- `segments.py`: segment PCA and profile/share plots.
- `classification.py`: confusion matrices.

Run `python src/run_all.py` from the repository root to regenerate the complete set after placing the UCI workbook at `data/raw/online_retail_II.xlsx`. Committed PNGs are snapshots from a prior run; regenerate them whenever upstream data or code changes, and do not treat old images as proof that the current pipeline has been rerun.
